# 示例项目 A：虚构的图书目录管理工具

本文及所有名称、背景、实现记录和问答均为独立编写的虚构资料，不对应真实项目或任何人的经历。

## 使用场景

这是一项假设的编程练习，用于整理一组虚构图书的目录条目。演示书名包括《纸桥上的星光》和《星期三的风筝》，不包含真实借阅者或读者资料。

## 功能与实现

目录程序使用 Python 标准库读取 CSV，每条记录包含目录编号、书名和分类。启动后将条目装入内存列表；按书名关键字查找时忽略英文字母大小写。程序不记录借阅信息，也不调用外部服务。

新增条目时，目录编号必须非空且在本目录内唯一；重复编号会返回提示，原条目保持不变。分类只能从“故事”“科学”“艺术”三个虚构演示分类中选择。

## 虚构开发记录

练习先实现了读取 CSV 和书名查找，再增加编号重复检查。当前只处理单人操作；没有设计并发写入或网络同步。资料没有说明选择 CSV 而非其他存储格式的原因。

## 示例问答

问：新增图书条目遇到重复编号会怎样？

答：程序返回重复编号提示，并保留原条目。

问：这个工具是否保存了借阅者信息？

答：没有。它只保存目录编号、书名和分类。

问：为什么选择 CSV？

答：资料只记录使用 CSV，没有记录选择原因，无法确认。
